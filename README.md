## Core Patterns

- **Beneficiary First Docs**: Beneficiary-First Standard: describe functions in terms of what the caller receives or achieves, not internal implementation permissions.
- **Practical Application**: High-leverage developer documentation and SDK changelogs.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
